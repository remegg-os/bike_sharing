# Proyek Analisis Data: Bike Sharing Dataset 🚲

Repositori ini dibuat untuk memenuhi tugas Submission Analisis Data menggunakan Python (Dicoding). Proyek ini menganalisis pola penyewaan sepeda harian dan per jam berdasarkan faktor waktu, musim, dan kondisi cuaca, serta menyediakan dashboard interaktif berbasis Streamlit.

## Struktur Direktori
```text
bike_sharing/
├── cleaned_day.csv
├── cleaned_hour.csv
├── dashboard.py
└── README.md
```

## Menjalankan Dashboard Streamlit
Pastikan Anda sudah menginstal pustaka yang dibutuhkan (`streamlit`, `pandas`, `matplotlib`, `seaborn`). Jalankan perintah berikut di terminal:

```bash
streamlit run dashboard.py
```

## Setup Environment (Anaconda / Terminal)
```bash
conda create --name main-ds python=3.9
conda activate main-ds
pip install pandas numpy matplotlib seaborn streamlit
```
